WPS Install Guard 1.2.0

WPS снова появился без приглашения? Возьми установку под контроль.

1. Распакуй архив в постоянную папку.
2. Запусти WpsInstallGuard.exe и подтверди запрос прав администратора.
3. Программа сообщит, что работает в трее. Найди зелёный значок W рядом с часами
   или под стрелкой скрытых значков.
4. Левый клик открывает окно, правый — меню управления.
5. Включи «Автозапуск с Windows», если защита должна запускаться при входе.
6. Нажми «Проверка»: безопасный имитатор должен быть остановлен.

При блокировке показывается путь к найденному файлу. Если включена опция
«Удалять файл в карантин», подходящий EXE убирается из исходной папки.

Журнал и карантин:
%LOCALAPPDATA%\WpsInstallGuard

Обновление: выйди из старой версии через меню трея, замени EXE в той же папке
и запусти новый. При сохранении пути автозапуск менять не нужно.

Файл не подписан сертификатом; Windows покажет неизвестного издателя.
Проверь контрольную сумму по SHA256SUMS.txt, приложенному к релизу.

Программа реагирует после запуска процесса. Возможны пропуски и ложные
срабатывания. Подробности, сборка и восстановление файлов — в README.md.
