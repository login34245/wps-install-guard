# WPS Install Guard 1.2.0 — WPS без приглашения? Установка под контролем.

Первая публичная версия WPS Install Guard: небольшая программа для Windows 11 Home, которая остаётся в трее, останавливает распознанные процессы WPS / Kingsoft и показывает путь к найденному файлу.

## Что внутри

- Перехват запуска WPS / Kingsoft и остановка дочерних процессов.
- Уведомления в углу экрана, локальный журнал и восстанавливаемый карантин для EXE.
- Значок в трее, левый клик для окна и правый для меню.
- Автозапуск с правами администратора через Планировщик заданий.
- Строгий режим и безопасная кнопка проверки без установки WPS и 360.
- Исправленная нижняя панель: крупные кнопки по DPI, несколько рядов на узком окне и зарезервированное место без перекрытий.

## Как начать

Скачай `WpsInstallGuard.exe` или ZIP с инструкцией, положи EXE в постоянную папку и запусти с подтверждением UAC. Программа сообщит, что работает в трее. Кликни по зелёному значку W, включи автозапуск при необходимости и нажми «Проверка».

Для обновления закрой предыдущую версию через меню трея «Выход» и замени EXE в той же папке.

## Проверки

Прошли 7 проверок распознавания, сквозной тест остановки безопасного имитатора, проверки трёх размеров окна и 32 проверки нижней панели при расчётном масштабе 100–300%. Реальный 360 Total Security для тестов не устанавливался.

## Перед использованием

Защита реагирует после запуска процесса и не гарантирует остановку до самого первого действия установщика. Возможны пропуски и ложные срабатывания. Карантин содержит перемещённый EXE, а не полную резервную копию установленного пакета. EXE не подписан цифровым сертификатом; контрольные суммы находятся в `SHA256SUMS.txt`.

В комплекте: `WpsInstallGuard.exe`, ZIP с русской инструкцией и SHA-256 для обоих файлов.
